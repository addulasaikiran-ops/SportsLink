# Organizations — page-specific UX rules

## User goal
Discover clubs, academies, leagues, and sports organizations to follow.

## Behavior
- Search organization name and organization type.
- Follow state toggles visibly and has an undo path.
- Empty results should explain how to broaden the search.
- Organization creation must be a real authorized workflow before being exposed as a production action.
- Cards consistently show identity, category, description, location, follower count, and follow action.
