# Settings — page-specific UX rules

## User goal
Understand and control profile, privacy, and notification preferences.

## Behavior
- The selected settings section is visually and semantically announced.
- Switch controls use role=switch, accessible labels, and aria-checked.
- Keep form labels visible; placeholders alone are not labels.
- Explain whether changes save immediately or require Save changes.
- Do not present editable settings until changes are persisted and enforced by the server.
- Production privacy controls must reflect real server enforcement, not merely change the UI.
