# Opportunities — page-specific UX rules

## User goal
Find a relevant sports role and understand the next step.

## Behavior
- Search matches title, organization, and category.
- Saved opportunities have a clear selected state and can be unsaved.
- Empty results offer a clear-search action.
- Distinguish “view details”, “save”, and “apply” as separate intents.
- Show only server-backed opportunities. Keep applications unavailable until their persistence and authorization path exists.
- Future role pages should include location, work type, compensation when available, eligibility, posting date, application deadline, and a clear application path.

## Responsive
- Job title and save action must stay usable at mobile widths.
- Metadata should wrap without overlapping the main CTA.
