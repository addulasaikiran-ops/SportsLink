# Profile — page-specific UX rules

## User goal
Present a credible sports career and discover relevant opportunities and collaborators.

## Content hierarchy
Identity and sport → role/headline → location/contact → skills → experience → achievements → analytics.

## Behavior
- Editing controls must be clearly separated from read-only presentation.
- Save and cancel need meaningful behavior; if changes are not persisted, disclose that before editing.
- Profile images have meaningful alt text when they convey identity.
- Skills and achievements should be editable only in an authenticated production flow.
- Avoid implying a verified badge or profile analytics are real unless sourced from trusted data.
